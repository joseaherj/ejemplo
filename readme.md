# MVC

Paquete de Python desarrollado como un proyecto estudiantil para el análisis y procesamiento de datos astronómicos.

> Estado: Proyecto estudiantil / Software educativo

## Descripción

MVC es un paquete de Python desarrollado con el objetivo de aplicar y practicar conceptos de programación científica, análisis de datos y desarrollo de software.

El proyecto busca proporcionar una estructura sencilla y reutilizable para trabajar con datos astronómicos y realizar diferentes procedimientos de análisis y visualización.

Este paquete fue desarrollado principalmente con fines educativos y puede encontrarse en proceso de desarrollo.

## Características

El paquete permite, dependiendo de la versión actual del proyecto:

- Cargar y manipular datos astronómicos.
- Trabajar con datos tabulares mediante Pandas.
- Realizar cálculos estadísticos básicos.
- Procesar parámetros físicos y observacionales.
- Generar gráficos y visualizaciones.
- Organizar diferentes procedimientos de análisis en módulos.
- Reutilizar funciones y clases desarrolladas en Python.

Nuevas funcionalidades pueden incorporarse a medida que avance el proyecto.
